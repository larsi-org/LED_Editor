# Eagle

Schematic (`.sch`) and board (`.brd`) files for the two custom Arduino
shields, drawn in [Autodesk Eagle](https://www.autodesk.com/products/eagle/overview).

- `LED_6x5_Shield/` - shield for the [LED 6x5](https://larsi.org/make/led_6x5)
  project: 30 LEDs wired as a 6x5 grid
- `LED_Cube3_Shield/` - shield for the [LED Cube3](https://larsi.org/make/LedCube3)
  project: 27 LEDs wired for a 3x3x3 cube

The [Schneeflocke](https://larsi.org/make/Schneeflocke) project has no shield
here - it drives a WS2812B addressable LED strip directly from an Arduino, so
there's no custom PCB to lay out.
